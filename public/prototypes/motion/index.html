TOKENS, STATES, RULES

TOKENS

--tw-ease-firmcubic-bezier(.2,.8,.2,1) — reveals, drops, hover --tw-ease-settlecubic-bezier(.3,1.4,.4,1) — arrivals only, sparingly --tw-ease-inoutcubic-bezier(.45,0,.25,1) — blink, rook turn --tw-t-draw1600 ms drawn in one line (house ident length) --tw-t-brick980 ms brickwork (48 ms/course) --tw-t-reveal640 ms castling --tw-t-drop520 ms placed (+50 ms crown lag) --tw-t-rise900 ms ink-rise reveal (mask fill + swap) --tw-t-blink380 ms idle blink --tw-t-turn380 ms merlon (110 ms stagger) --tw-t-loop2000 ms loop period --tw-t-hover160 ms hover nudge --tw-t-rise900 ms ink rise (progress-capable) --tw-t-turn700 ms sentry turn, perspective 600 --tw-t-stamp240 ms letterpress dip --tw-t-sundial1800 ms shadow sweep, opacity ≤ .09 --tw-t-breath4200 ms ambient swell, 0.65% --tw-t-build1240 ms tower build (default opening) --tw-t-light1300 ms light pass, runs once after build

WHERE EACH STATE RUNS

Reveal — header/hero first paint, admin login. Once per session.
Idle — header mark only. 6–9 s randomized, ≤380 ms.
Hover/focus — logo links. 160 ms, reversible.
Ident — logo click, order confirmed. Gate below 48 px.
Loop — route transitions, admin processing. Stops at rest.

NEVER

Never on checkout actions · never looping in viewport while the user types · never more than one animated mark visible · reduced motion is skipped, not shortened · never delay interaction or shift layout.
